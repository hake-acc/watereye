==================================================

Preserve the existing card dimensions as much as possible.

The card should have:

on the main visual card wrapper so the background gradients never escape through the rounded corners.

==================================================

Create the visual background using layered CSS rather than inserting a static image.

Prefer CSS gradients / pseudo-elements.

DO NOT use a screenshot as the background.

Recommended architecture:

==================================================
5. UPPER REGION
==================================================

The upper ~30–40% of the card should contain a subtle brand-tinted atmosphere.

Do NOT make it a flat solid colour.

Use a very subtle gradient.

Conceptually:

background:
linear-gradient(
  to bottom,
  <brand-tint-dark>,
  <brand-tint-deeper>
);

The upper area should be visibly lighter than the lower area but still remain dark.

Avoid:
- bright purple
- neon purple
- saturated gradients
- glassmorphism
- excessive blur
- obvious gradient bands

The colour must be derived from OUR EXISTING BRAND COLOUR SCHEME.

Do not introduce a completely unrelated purple palette just because the reference uses purple.

Translate the visual relationship of the reference into our palette.

In other words:

REFERENCE:
dark purple upper atmosphere
+
almost-black lower atmosphere

OUR VERSION:
brand-coloured upper atmosphere
+
our existing dark background lower atmosphere.

==================================================
6. LOWER REGION
==================================================

The lower region must be significantly darker.

It should visually approach the existing website background.

The lower background should not simply be:

background: #000;

Instead, use a very subtle tonal gradient so it retains depth.

Conceptually:

linear-gradient(
  to bottom,
  <dark-brand-neutral>,
  <existing-site-dark-background>
);

The goal is for the lower section to visually merge with the surrounding dark website without completely disappearing.

==================================================
7. HORIZONTAL TRANSITION
==================================================

THIS IS ONE OF THE MOST IMPORTANT DETAILS.

The upper and lower regions meet through a clean horizontal boundary.

The reference does NOT have a soft full-card gradient where everything gradually transitions.

Instead, the visual structure is closer to:

UPPER ATMOSPHERE
████████████████████████████

──────────── transition ────────────

LOWER DARK SURFACE
████████████████████████████

Create this transition using either:

- layered pseudo-elements
- background gradients with carefully controlled stops
- a dedicated transition layer

The transition should be almost perfectly horizontal.

Do NOT make it diagonal.

Do NOT make it wavy.

Do NOT make it circular.

Do NOT make it look like a generic hero gradient.

==================================================
8. AVATAR OVERLAP
==================================================

The avatar is the visual anchor.

It MUST overlap the upper/lower background boundary.

The avatar should sit approximately 50% above and 50% below the transition area, depending on the existing card dimensions.

Use positioning similar to:

position: absolute;
left: 50%;
transform: translateX(-50%);

and position it so its center is approximately aligned with the transition line.

However, DO NOT blindly use fixed pixel values.

Make the placement responsive relative to the card.

The avatar should appear to physically emerge from the card background.

It must have:

- circular clipping
- subtle dark border/ring
- subtle shadow
- enough contrast from both background regions
- no accidental rectangular image edges

The existing creator avatar must be used.

==================================================
9. AVATAR HALO / LOCAL CONTRAST
==================================================

There is subtle visual separation around the avatar.

Recreate this with a restrained shadow/halo.

Example conceptual structure:

box-shadow:
0 0 0 3px rgba(...),
0 8px 24px rgba(0,0,0,.45);

BUT:

Do not blindly copy these values.

Tune them against the existing colour scheme.

The halo should make the avatar readable against the transition.

It should NOT look like a neon ring.

==================================================
10. CARD BORDER
==================================================

The reference card has a very subtle border.

Use a low-opacity border derived from the site's palette.

Something conceptually similar to:

border: 1px solid rgba(<brand>, 0.12);

But calculate the actual value from the existing design system.

The border should become slightly more visible around the upper region because of the contrast.

Do NOT use a bright solid border.

==================================================
11. CARD SHADOW
==================================================

The card should separate from the page using a large, soft, dark shadow.

Use a layered shadow if necessary.

Conceptually:

box-shadow:
0 20px 50px rgba(0,0,0,.30);

Potentially combine with a very subtle brand-tinted ambient shadow.

The effect must remain understated.

No glowing purple neon card shadow.

==================================================

==================================================
